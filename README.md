<h1 align="center">🛒 Basic E-commerce Frontend</h1>

<p align="center" style="font-size: 18px;">
  ✨ A clean and interactive frontend for a basic e-commerce website featuring smooth animations on scroll and integrated Google Maps for store location display. Designed for great user experience and responsiveness.
</p>

<p align="center">
  <a href="https://deepak-05dktopg.github.io/host-ecommerce/" target="_blank"><strong>🌐 Live Demo</strong></a>
</p>

<hr/>

<h2>🚀 Tech Stack</h2>
<ul>
  <li><strong>Frontend:</strong> 🌐 HTML5, 🎨 CSS3, 💡 JavaScript (Vanilla)</li>
  <li><strong>Animations:</strong> ✨ Animation on Scroll (AOS) Library</li>
  <li><strong>Map Integration:</strong> 🗺️ Google Maps API</li>
  <li><strong>Deployment:</strong> 🚀 GitHub Pages </li>
</ul>

<h2>✨ Features</h2>
<ul>
  <li>📱 Responsive design for all devices</li>
  <li>🎞️ Smooth animations triggered on scroll</li>
  <li>🗺️ Google Maps embedded to show store location</li>
  <li>🛍️ Product listing with basic UI</li>
  <li>🔗 Navigation links for easy browsing</li>
</ul>
